# QA Checklist для проверки рыночных ситуаций SMC

## 1. Базовые сигналы и их валидация

### Order Block (OB)
- [ ] Проверить корректность определения направления (bullish/bearish)
- [ ] Подтвердить уровень формирования (swing/internal)


### Change of Character (CHoCH)
- [ ] Подтвердить наличие предшествующего тренда
- [ ] Проверить контекст POI для усиления сигнала
- [ ] Различать обычный CHoCH и CHoCH+ (усиленный)
- [ ] Проверить наличие подтверждающего BOS
- [ ] Оценить силу предшествующего тренда (минимум 3 последовательных свинга)
- [ ] Убедиться в отсутствии сильных уровней препятствующих развороту

### Break of Structure (BOS)
- [ ] Подтвердить нарушение предыдущей структуры
- [ ] Проверить уровень (swing/internal)
- [ ] Проверить взаимосвязь с последующим CHoCH

## 2. Контекстная валидация

### Проверка Point of Interest (POI)
- [ ] Убедиться в актуальности POI (не инвалидирован)
- [ ] Проверить состояние цены относительно POI (within/exit)
- [ ] Подтвердить отсутствие противоречащих сигналов
- [ ] Проверить согласованность уровней (swing/internal)
- [ ] Убедиться в правильной последовательности входа и выхода из POI
- [ ] Проверить корреляцию POI на старших таймфреймах

### Последовательности сигналов
- [ ] BOS → CHoCH: проверить логическую связь
- [ ] OB/Imbalance → CHoCH: проверить усиление сигнала
- [ ] Breaker → Liquidity Grab: проверить взаимодействие
- [ ] Проверить отсутствие противоречащих сигналов в последовательности
- [ ] Убедиться в правильной временной последовательности
- [ ] Оценить временные промежутки между связанными сигналами

## 3. Инвалидация сигналов

### Order Block инвалидация
- [ ] Проверить пересечение в направлении формирования
- [ ] Подтвердить формирование противоположного BOS
- [ ] Проверить корректность определения выхода из зоны (exit)

### Imbalance инвалидация
- [ ] Проверить корректность определения выхода из зоны (exit)

### Breaker инвалидация
- [ ] Проверить пробой уровня в противоположном направлении

## 4. Особые ситуации

### Множественные POI
- [ ] Проверить взаимодействие близких POI
- [ ] Подтвердить приоритетность более свежих POI
- [ ] Убедиться в корректной обработке наложений
- [ ] Проверить взаимодействие разных типов POI (OB vs Imbalance)
- [ ] Оценить усиление сигналов при совпадении POI
- [ ] Проверить согласованность реакций на разных POI
- [ ] Убедиться в правильности определения доминирующего POI

### Смешанные уровни
- [ ] Проверить взаимодействие swing и internal уровней
- [ ] Подтвердить приоритет swing над internal
- [ ] Убедиться в правильной интерпретации смешанных сигналов
- [ ] Проверить согласованность сигналов разных уровней
- [ ] Проверить временную согласованность между уровнями
- [ ] Убедиться в отсутствии противоречий между уровнями

### Целевые imbalance
- [ ] Проверить наличие imbalance в направлении движения
- [ ] Подтвердить актуальность целевого разрыва
- [ ] Убедиться в логичности связи сигнал-цель
- [ ] Проверить достижение целевых уровней
- [ ] Проверить на наличие промежуточных препятствий

## 5. Критерии качества сигналов

### Высокое качество
- [ ] CHoCH в активном POI
- [ ] Наличие целевого imbalance
- [ ] Четкая структура рынка
- [ ] Отсутствие противоречащих сигналов
- [ ] Согласованность swing и internal уровней
- [ ] Наличие подтверждающих факторов (Breaker, Liquidity Grab)
- [ ] Согласованность на нескольких таймфреймах
- [ ] Отсутствие сильных препятствующих уровней

### Среднее качество
- [ ] CHoCH без активного POI
- [ ] BOS с четкой структурой
- [ ] OB/Imbalance с четким формированием
- [ ] Частичное подтверждение структуры
- [ ] Умеренное объемное подтверждение
- [ ] Частичная согласованность таймфреймов
- [ ] Наличие некритичных препятствий

### Низкое качество (требуют особого внимания)
- [ ] Противоречивые сигналы
- [ ] Нечеткая структура рынка
- [ ] Отсутствие подтверждающих факторов
- [ ] Смешанные сигналы разных направлений
- [ ] Неполные последовательности сигналов
- [ ] Отсутствие согласованности таймфреймов
- [ ] Наличие сильных противодействующих факторов
- [ ] Противоречие с глобальным трендом

## 6. Общие проверки

### Технические аспекты
- [ ] Корректность временных меток
- [ ] Отсутствие дубликатов сигналов
- [ ] Правильность определения направления
- [ ] Точность определения уровней
- [ ] Корректность обработки состояний (entered/within/exit)
- [ ] Проверка синхронизации данных
- [ ] Корректность определения таймфреймов

### Логические проверки
- [ ] Согласованность последовательности сигналов
- [ ] Отсутствие противоречий в контексте
- [ ] Правильность обработки состояний
- [ ] Соответствие сигналов общей структуре рынка

### Документация сигналов
- [ ] Полнота информации о сигнале
- [ ] Корректность нормализации
- [ ] Точность определения типа
- [ ] Правильность контекстной информации
- [ ] Корректность описания взаимосвязей между сигналами
- [ ] Фиксация важных рыночных условий
- [ ] Документирование особых ситуаций
- [ ] Отметка о потенциальных рисках
